Outlook Image & Attachment Helper with OCR

Version: 1.6.5 (Build: 20261107.2, Release date: 2026-11-07)

Author: Sławomir Strugarek (with the invaluable assistance of Antigravity — Google DeepMind)

Compatibility: NVDA 2024.1 – 2026.1+ | Microsoft Outlook 2013, 2016, 2019, 2021, Microsoft 365 (Classic desktop version)

License: Free, Open Source (GPL v2+)

An NVDA screen reader add-on providing full accessibility, local optical character recognition (OCR), magnified image preview for low-vision users, audio descriptions and interactive multi-turn chat with artificial intelligence (Google Gemini), prompt presets library, context-sensitive help (F1), hyperlink activation, file attachments support (PDF, Word DOCX, images), and batch saving for images and attachments in Microsoft Outlook Classic messages (WordMail editor).

Important Compatibility Notice — Microsoft Outlook Classic Only:
This add-on is designed and optimized strictly for the classic desktop version of Microsoft Outlook (Outlook Classic) on Windows (versions 2013, 2016, 2019, 2021, and classic Microsoft 365 with the WordMail editor). The "New Outlook for Windows" (a web-based Edge application) does not contain Microsoft Word's native COM object model and does not support screen reader add-ons of this type.

How It Works

Microsoft Outlook Classic renders message bodies using Microsoft Word's rendering engine (WordMail, window class _WwG). Embedded images belong to two categories:

  1. InlineShapes (in-line graphics): Typical pasted screenshots. When lacking alt text, standard NVDA only announces "graphic" without interactivity.
  2. Shapes (floating graphics with text wrapping): Banners, diagrams, company logos, social icons. NVDA's standard single-letter G command completely skips these.

Outlook Image Helper connects directly to the WordMail COM object model in process memory, identifying 100% of embedded graphics, extracting exact pixel dimensions, hyperlinks, alt text, and surrounding text context.

Message List Navigation (Reading Pane On vs Off)

The add-on seamlessly supports Outlook's message list (Explorer) across different reading pane configurations:

  • When Reading Pane is enabled: Outlook continuously renders the selected message. Pressing Ctrl+NVDA+A or quick OCR/AI shortcuts directly on the message list immediately inspects and displays all images and attachments without requiring opening the email in an Inspector window.
  • When Reading Pane is disabled (common among screen reader users): Outlook does not construct message bodies in memory. When invoking the add-on on the message list, it plays an alert tone, reports the message subject and detected file attachments, and guides you to open the email with Enter to inspect inline images.
  • When multiple messages are selected: The add-on announces the number of selected messages and how many contain attachments (e.g., "4 messages are selected (including 2 with attachments). To browse images and attachments, select a single message or open it with Enter.").

How to Unblock & Download Pictures in Outlook

For privacy and security, Outlook blocks automatic downloading of external internet pictures by default. You can unblock pictures in two convenient ways:

1. Quick unblock in current message:
  1. In an open message, press Ctrl + Shift + W. Focus immediately jumps to the Information Bar (InfoBar) at the top of the message and opens its dropdown menu.
  2. Press Enter (the first option in the menu is "Download Pictures").
  3. Outlook downloads all images. Press Ctrl + NVDA + A again to inspect, OCR, or describe them with AI.
2. Permanently enable automatic picture download across all messages:

To have Outlook automatically load pictures in all incoming HTML emails:

  1. In Outlook, go to: File → Options (shortcut: Alt+F, then T).
  2. In the Options dialog, select Trust Center.
  3. Press Tab to find "Trust Center Settings..." and press Enter.
  4. In the Trust Center window, select Automatic Download.
  5. Uncheck the checkbox: "Don't download pictures automatically in standard HTML email messages or RSS items" (or customize trusted senders).
  6. Click OK twice to save your settings.

Three Item Categories (Graphics / Attachments / Dividers)

Pressing Ctrl+NVDA+A displays the main dialog. At the top is the Category Switcher (Alt+K):

  1. 1. Inline graphics and screenshots in message body (Default): Content visuals, photos, screenshots, and diagrams (shortcut Alt+1).
  2. 2. Message attachments: Real files attached to the email (multi-page PDF documents, Word files, spreadsheets, attached image files) (shortcut Alt+2).
  3. 3. Divider lines and horizontal separators: Decorative separator lines and rules (thin elements ≤ 3 px). Separated to keep the primary visual list clean and focused (shortcut Alt+3).

Directly beneath the details box is the "Group repeating images (deduplication)" checkbox (Alt+A), allowing you to hide duplicate avatars and icons.

Magnified Image Preview & Color Inversion for Low-Vision Users (P / I)

For users with residual vision or low vision, the add-on provides a dedicated image previewer with high magnification and high-contrast color inversion:

  • Press P or click "Preview (P)..." on any graphic in the list.
  • Contrast & Centering: Images are presented against a solid dark high-contrast background with smooth double-buffered scaling.
  • Keyboard Zoom: Press + to zoom in, - to zoom out. NVDA announces current zoom level aloud (e.g. "Zoom: 200%").
  • Color Inversion (Negative Mode) — Key I: Instant C-level byte array color inversion (dark background, bright text) preserving full Alpha channel transparency. Essential for reading bright white screenshots on dark setups.
  • Persistent Inversion Memory: Pressing I (in preview or directly on the graphics list) saves your preference to outlookImageHelper_image_settings.json for that specific email. The graphic displays [Inverted] in the list and automatically opens inverted on future visits.
  • Quick Outlook Shortcut (NVDA+Windows+I / Alt+Shift+I): Instantly opens the negative preview directly from message reading mode.
  • Quick Sizing: Press 0 or D to fit image perfectly to window; press 1 for 100% natural resolution.
  • Open in Windows (O): Press O to open the graphic in the default Windows image viewer (opens the negative version when inversion is active).
  • Replace Graphic in Email Body: The Context Action Menu allows replacing the image inside the message body with its negative counterpart (when WordMail is in Edit Message mode), while explaining write-protection in read-only emails and offering persistent preview as a safe non-destructive alternative.
  • Press Esc to close the preview and return to the list.

Context-Sensitive Help (F1)

Help is available anywhere at any time without leaving your workflow:

  • Press F1 in any dialog (Graphics List, AI Chat, Image Preview, or Settings).
  • NVDA immediately displays a clean, browseable buffer containing helpful guidance, keyboard shortcuts, and tips strictly relevant to that specific window.
  • Press Esc to dismiss help and immediately resume what you were doing.

File Attachments Analysis & OCR (PDF, DOCX, Images)

  • PDF Documents (Scans and text files): Choosing Transcribe text from PDF scan or AI PDF Analysis sends the file to Google Gemini multimodal AI (native Base64 application/pdf). Gemini transcribes text, detects tables, headers, invoice amounts, and due dates without requiring third-party PDF OCR software!
  • Word Documents (DOCX): Built-in OpenXML reader extracts paragraphs and table structures instantly from the file package without launching Microsoft Word.
  • Image Attachments (PNG, JPG, BMP, WEBP, TIFF): Supports both local Windows Media OCR and AI descriptions.
  • Opening & Saving: Press Ctrl+Enter to open attachments in their default application or save them individually or in batches.

Context Action Menu

Press Applications, Shift+F10, or Alt+C on any selected item:

Available operations:

  • Recognize text (OCR) (Enter): Fast local Windows OCR or AI transcription.
  • Magnified image preview (P): Opens the high-contrast zoom viewer.
  • Describe with AI (Quick): Instant description using the default prompt preset.
  • Describe with AI (Choose Prompt): Select or customize prompt templates.
  • Chat with AI (Q&A): Interactive multi-turn conversation.
  • Open link / file (Ctrl+Enter): Opens hyperlink in browser or opens attachment file in default app.
  • Go to graphic in message: Physically selects the graphic in WordMail.
  • Copy image to clipboard: Copies the bitmap to the Windows clipboard.
  • Save selected item as file... (Alt+Z): Saves item with a descriptive name.
  • Save all items to folder... (Alt+W): Batch exports all items to a chosen folder.

Accessible AI Chat (Unified Window, Heading Navigation, Action Buttons)

The conversation dialog operates in a single, accessible window styled after modern AI interfaces:

Structure and navigation shortcuts in the AI chat:
  • Heading Navigation (H and Shift+H): Press H to jump between questions, AI answers, and subheadings within markdown. Press Shift+H to jump backwards. NVDA announces heading levels and titles, and pressing Down Arrow reads the text immediately.
  • Interactive Links, Emails, Phones & GEO (K, Shift+K, Enter): Any URLs, Markdown links, email addresses, phone numbers, or geographic coordinates detected in AI responses are formatted and highlighted with high contrast. Press K to jump to the next link, Shift+K for previous, and press Enter (or click) to open in the system default application (browser, mail client, phone dialer, or maps). Press L for a popup menu listing all detected links.
  • Dedicated buttons under each response:
    • "Copy response X to clipboard" — copies only that specific response (Plain Text + Rich HTML with source image),
    • "Save response X to file..." — exports that specific response as HTML, Markdown (.md), or plain text (.txt).
  • Button Navigation (B and Shift+B): Cycles directly through action buttons under responses and on the bottom toolbar.
  • Jump to Input Field (E): Moves focus immediately to the question input field.
  • Send Questions: In the question input field, press Enter or Ctrl+Enter to send. Press Shift+Enter for a new line.
  • Quick History Actions: When focused on a response, press C to copy it or S to save it.
  • Acoustic Progress Cues: Gentle beeps sound every 1.5 seconds while waiting for Gemini, followed by a success chime and automatic focus placement on the new answer.

Universal Rich Copy & Export

  • Per-answer action buttons: Copy and save individual answers without needing to copy the whole conversation.
  • Copy last response (Alt+O): Copies only the most recent AI answer.
  • Copy entire conversation (Alt+C): Copies the complete Q&A transcript.
  • "Include source object" checkbox: Places Rich HTML with embedded Base64 image onto the clipboard. Pasting into Outlook or Word embeds the original image alongside styled text. Pasting into Notepad outputs clean plain text.
  • Export report to file...: Saves the full conversation as a self-contained .html report or .md Markdown document.

Custom Graphic Naming (F2) & Persistent Memory

  • Clean Labels: Default list labels are clean and concise (e.g. 16: Screenshot).
  • Rename / Custom Description (F2): Select an image and press F2 (or choose from the Context Menu). Enter a friendly name, such as Vacation Schedule - IT Team.
  • Persistent Storage: The custom name is immediately saved in the add-on database linked to the email's unique ID. Reopening the email — even after restarting your PC — preserves your custom name (e.g. 16: [Vacation Schedule - IT Team]).
  • Safe & Non-intrusive: No modification of emails on the server. If the email is editable, the name is also written to WordMail alt text in memory.
  • Reset Name: Select "Remove custom name (restore default)" in the Context Menu.

Navigation Earcons & Audio Themes

While navigating the list with arrow keys, subtle audio cues indicate the type of item:

  • Social media icon: Double rising tone.
  • Phone number: DTMF phone dialing tone.
  • Email link: Mail envelope rustle.
  • Web hyperlink: Clean interface click.
  • Divider line / separator: Soft pencil tap.
  • Screenshot / unlabeled image: Camera shutter notification.

Navigation sounds can be enabled or disabled anytime in NVDA Preferences.

Batch Saving & Clean Filenames (GDPR)

  • Click "Save all..." or select multiple items with Space to export all files at once.
  • Filenames are automatically generated from context (e.g. 01_John_Doe.png).
  • Privacy & GDPR: Filename generation runs 100% locally on your computer without sending any data externally. AI filename generation is optional and disabled by default.

Free Google Gemini API Key Setup

The Google Gemini API key is 100% free for personal use. No credit card or payment is required.
  1. Go to: https://aistudio.google.com/app/apikey.
  2. Log in with your Google account (Gmail).
  3. Click "Create API key" and select a new project.
  4. Click "Copy" to copy the generated key.
  5. In Outlook, press Ctrl+NVDA+A → Shift+F10 → "Go to add-on settings..." (or open NVDA menu → Preferences → Settings → Outlook - Pomocnik obrazów i OCR), check "Show advanced settings" and paste the key.

OpenAI (ChatGPT API) Key Setup

Unlike Google Gemini, which offers a generous free tier for personal Google accounts, the OpenAI platform (ChatGPT API) requires adding billing credit (e.g. $5 USD) under the Billing section in your OpenAI developer account.
  1. Open OpenAI API keys in your browser: https://platform.openai.com/api-keys.
  2. Log in or register an OpenAI account.
  3. Click "Create new secret key".
  4. Provide an identifier name (e.g. NVDA Outlook) and confirm.
  5. Copy the generated secret key (starts with sk-...). Store it safely as OpenAI only shows the full key once.
  6. In add-on Advanced Settings, switch the provider to OpenAI (ChatGPT), paste the key into OpenAI API Key, and click "Test OpenAI API Key".

Add-on Settings in NVDA Preferences

Located in NVDA menu → Preferences → Settings → Outlook - Pomocnik obrazów i OCR. The interface is split into Basic and Advanced modes:

  • Basic Mode (Default):
    • Announce pasted graphics on open: Topmost option of the panel — speech cue when opening messages with pasted images.
    • Alert Sound & Earcons: Discretionary audio chime when graphics are found, trigger mode choice, and list navigation sounds.
    • Notification Sound Theme: Selection of 3 distinct themes (Associative — camera shutter, Minimalist, Instrumental) with a Preview sound button.
    • Sound Volume: Volume slider with full keyboard control and test button.
    • Input Gestures & User Guide buttons.
  • Advanced Mode (Checkbox "Show advanced settings"):
    • Interface Language: Auto (matches NVDA), Polski, English.
    • Default OCR Language: Dropdown selection of installed Windows Media OCR languages and custom language code.
    • Diagnostic Report (Alt+R): Comprehensive summary of system status, OCR engine availability, and AI connectivity.
    • Artificial Intelligence (AI): AI filename generation, provider choice (Google Gemini / OpenAI), API key field, wizard dialog, connectivity test, model selection (default: gemini-3.8-flash), and custom prompt template.
    • Add-on Updates: Option to check for updates on NVDA startup and a button to check immediately.
    • Creator Tools (Alt+N): Located at the very bottom of the advanced panel, protected by creator password (with password change and recovery via a 6-digit verification code sent to the author's authorized email). Houses AI translation tools, JSON language template import/export, translations folder, and the update definition path.
